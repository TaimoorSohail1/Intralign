## Decision

1. **Pro program support = a cross-plan EXECUTION COGNITION layer (Bundle A adopted).** A **program** = a set of **related plans under one owner**, worked as one effort. Pro's program layer adds cognition that only exists *across* plans (it never improves a single-plan read — same accuracy bar). **In scope at Pro:** program roll-up view; cross-plan dependency mapping; program-level continuous monitoring; under a **program-envelope** capacity cap. **Out of Pro:** multi-user collaboration/governance (Team); cross-owner / org-scale portfolio cognition (Enterprise; DL-034); any higher-quality single-plan read (judgment quality never tiered — DL-104).

2. **The program roll-up is an AGGREGATE, never a composite verdict (doctrine-hard).** It aggregates the individual outcome-integrity reads such that **every figure is decomposable and traceable to a specific plan / dimension / issue** (single-hue maturity, cross-plan dependencies, a prioritized cross-plan worklist). It is **NEVER** a rolled-up "program health score," traffic-light, or **probability/forecast of program success** (D003/D183b; single-hue rule; DL-062 decomposability). Test: if a number can't be clicked down to its source read, it is not allowed.

3. **Pro price = $79/mo — RATIFIED (amends DR-7).** Drop the placeholder (`_PRICING.pro.ph = true → false`); **supersede DR-7's "PROVISIONAL / finalize later" note** — $79 is now backed by the Bundle A scope and a defined higher-WTP buyer (program / PMO lead). The floated **$69 compression is closed** in favor of $79. **Standing rule preserved (Tier register #9):** like every number, $79 remains an instrumented hypothesis — **confirmed at launch against reverse-trial / intent telemetry, adjustable only by evidence** (easy to loosen, painful to tighten); it is not frozen from spec. Flat, per-account, never per-seat (DR-7).

4. **Terminology — adopt US "program" as canonical**, superseding British "programme" in prior canon (Tier Def §1, DL-083, DL-104, DL-206). Route to the DL-053 register with a doc-integrity find-and-replace.

5. **Phase.** Program layer is **Beta+** (with execution monitoring, DL-083 / DL-206). **No R2 build impact** (DL-172 §5). Authorizes no build; realization routes to its own scoping.

## Doctrine preserved (unchanged)

Single-hue outcome integrity — never health/traffic-light, never forecast (D003/D183b). One accuracy bar for all — Pro buys cross-plan *scope of cognition*, never a better read (DL-103 §1 / DL-104). Record, reviewers/CRR, Viewers free/unmetered (DL-102). Flat per-account (DR-7). Outcome-based pricing prohibited (DL-103 §7h).
