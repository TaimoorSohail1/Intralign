## Confidence Inputs

Confidence should consider:
- clarity
- alignment
- feasibility
- evidence strength
- assumption stability
- stakeholder coverage
- dependency stability
- governance state
- understanding boundaries

# Confidence Display Rules

## Always show:
- current confidence
- confidence maturity
- trend direction

## On click show:
- dimension decomposition
- primary drivers
- evidence basis
- understanding boundaries
- historical movement

---

# Confidence Change Rules

When confidence changes meaningfully:
- update shell
- log event
- identify drivers
- expose explanation
- show affected dimensions

---

# Confidence Maturity Rules

## Initial
Show label clearly.
Avoid implying complete understanding.

## Expanded
Show what was added by deep refinement.

## Validated
Show validated evidence and stakeholder inputs.

## Continuous
Show monitoring sources and telemetry coverage.

---

# Integrity Gap Logic

Integrity Gap = divergence between Intended Reality and Current Reality.

Display when:
- intended goal conflicts with current feasibility
- alignment diverges
- assumptions weaken
- execution telemetry contradicts plan
- stakeholder interpretation changes

---

# Understanding Boundary Logic

Show understanding boundary when:
- evidence missing
- integration unavailable
- stakeholder input incomplete
- source reliability weak
- analysis depth limited
