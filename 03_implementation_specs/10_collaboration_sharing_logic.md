# Collaboration & Sharing Logic

## Collaboration Layers

1. Artifact-Level
2. Intelligence-Level
3. Understanding-Level

---

# Artifact-Level Collaboration

Supports:
- comments
- annotations
- section review
- artifact-level feedback

Example:
Share Intent View for review.

---

# Intelligence-Level Collaboration

Supports:
- issue discussion
- assumption validation
- recommendation review
- conflict clarification

---

# Understanding-Level Collaboration

Supports:
- interpretation approval
- understanding correction
- executive alignment
- governance decision review

---

# Sharing Permissions

Possible roles:
- Viewer
- Commenter
- Clarifier
- Approver
- Governance Reviewer
- Owner

---

# Shared View Types

- Executive Snapshot
- Artifact Review
- Understanding Snapshot
- Governance Review
- Clarification Request
- Scenario Summary

---

# Sharing Progression

Default:
read-only understanding.

Optional:
comment and clarify.

Advanced:
approval and governance actions.
