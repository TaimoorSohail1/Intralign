# Architecture

This domain holds engineering-oriented technical architecture. Content here is **derived** from Doctrine and Constitution and operationalizes how OSLO is built.

## Current Content

- `runtime_architecture/` — Runtime state logic and state machines.
- `judgement_layer/` — Confidence and integrity logic.
- `governance_layer/` — Governance override logic.
- `components/` — Component system specification.

## Precedence Posture

Architecture content is **derived** from Doctrine and Constitution. State machines, component schemas, integration models, and agent behaviors operationalize doctrinal positions. Concepts introduced here without doctrinal anchor are provisional and feed Revision Backlog items (RB-004 and related).

## Citation Rules

Architecture documents must cite the doctrinal or constitutional source they implement where applicable.

## Engineering Discipline

Architecture content asserts how OSLO is built, not what OSLO is.
