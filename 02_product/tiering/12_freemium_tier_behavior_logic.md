# Freemium / Tier Behavior Logic

## Freemium Should Include

- multi-input intake
- sample project buttons
- fast-pass confidence
- deep refinement
- basic Outcome Space
- limited fixes
- basic attention queue
- PDF/export snapshot
- lightweight sharing

---

# Freemium Constraints

Constrain:
- number of Outcome Spaces
- number of daily fixes
- number of simulations
- continuous monitoring
- integrations
- team collaboration depth
- governance policies
- export/sync capabilities

---

# Upgrade Prompt Rules

Do not show persistent upgrade wallpaper.

Upgrade prompts should be:
contextual and value-based.

Example:
After user improves confidence:
"Continuous monitoring can protect this confidence over time."

---

# Professional Tier

Unlock:
- continuous monitoring
- unlimited or expanded fixes
- more simulations
- execution integration
- richer artifact optimization

---

# Team / Business Tier

Unlock:
- collaboration
- shared spaces
- approvals
- execution synchronization
- advanced shared views

---

# Enterprise Tier

Unlock:
- governance policies
- organizational thresholds
- portfolio cognition
- agent governance
- cross-system orchestration
