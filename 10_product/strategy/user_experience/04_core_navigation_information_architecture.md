# Navigation Rules

## Rule 1 — Understanding First

Understanding is the home concept.

Do not make:
- artifacts
- tasks
- chat
- reports

the default conceptual center.

---

## Rule 2 — Artifacts Are Grouped

Artifacts should be nested under Artifacts.

Primary artifacts:
- Intent
- Context
- Execution
- Schedule
- Resources

Do not overcrowd top-level navigation with every artifact type.

---

## Rule 3 — Attention Is Persistent

Attention Queue should be visible as:
- nav item
- top shell count
- workspace section

Attention should sort by outcome impact by default.

---

## Rule 4 — Evolution Is First-Class

Understanding Evolution should not be buried inside activity logs.

It represents:
meaning change over time.

---

## Rule 5 — Governance Is Separate but Connected

Governance includes:
- policies
- thresholds
- overrides
- approvals
- escalation
- decision rationale

Governance is not merely admin settings.
