# Product Shell & Layout Wireframe

## Purpose

Define the persistent OSLO application shell for the long-term Outcome Space experience.

This shell is separate from the 60-second PLG onboarding flow.

---

# Persistent Layout

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ Outcome Space: Customer Onboarding Transformation                           │
│ Confidence: 82 ↑4 | Clarity 78 | Alignment 86 | Feasibility 74 | Attention 3 │
├───────────────┬───────────────────────────────────────────────┬─────────────┤
│ LEFT NAV      │ CENTER WORKSPACE                              │ OSLO PANEL  │
│               │                                               │             │
│ Understanding │ What OSLO Understands / Artifact / Attention  │ Contextual  │
│ Artifacts     │                                               │ Companion   │
│ Attention     │                                               │             │
│ Simulations   │                                               │ Ask / Fix / │
│ Evolution     │                                               │ Explain     │
│ Governance    │                                               │             │
├───────────────┴───────────────────────────────────────────────┴─────────────┤
│ Bottom Tray: Evidence | Lineage | Timeline | Comments | Reasoning           │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

# Top Confidence Shell

Always visible.

Contains:
- Outcome Space name
- Outcome Confidence
- Clarity
- Alignment
- Feasibility
- Attention Queue count
- Integrity State
- Confidence Maturity

Example:

```text
Customer Onboarding Transformation
Confidence 82 ↑4 | Expanded | Clarified but Fragile
Clarity 78 | Alignment 86 | Feasibility 74 | Attention 3
```

---

# Left Navigation

Primary nav:
- Understanding
- Artifacts
- Attention
- Simulations
- Evolution
- Governance

Artifacts expands:
- Intent
- Context
- Execution
- Schedule
- Resources

---

# Center Workspace

Adaptive.

Possible modes:
- Understanding Overview
- Artifact Workspace
- Attention Queue
- Simulation Workspace
- Evolution Timeline
- Governance Review
- Executive Narrative View

---

# Right OSLO Companion

Contextual, not global chat-first.

States:
- collapsed
- ambient
- active assist
- guided clarification
- governance escalation
- simulation support

---

# Bottom Tray

Expandable inspector.

Tabs:
- Evidence
- Lineage
- Timeline
- Comments
- Reasoning
- Source Artifacts

Default:
collapsed unless user inspects confidence, recommendation, issue, or governance state.

---

# Design Rule

The shell should feel calm and stable. Intelligence should become more visible only when uncertainty, consequence, or governance severity increases.
