## Decision

The product term **"Initial Analysis"** — the Fast Pass, the quick first read delivered on intake — is renamed to **"Preliminary Outcome Analysis."** All occurrences in the deliverable were updated in one pass (the analyzing-screen label, the completion chat notice, the History run label, the GA anonymous-run copy, the first-run notes); none remain.

This completes the naming pair begun in DL-138. The two-pass model now reads coherently under one noun:

- **Preliminary Outcome Analysis** — the fast first read (was "Initial Analysis").
- **Outcome Analysis** — the deeper pass that firms it (was "Extended Analysis").

Both name the run that produces and firms **Outcome Confidence** (the read). "Preliminary" carries exactly what the fast pass is — a first, provisional reading — where "Initial" only marked order.

## Guardrails

- **Terminology only** — no behaviour, cost, cadence, or state-machine change; the Fast/Deep two-pass model (D031/D036/D040), the ~60-second target, and the token budget (DL-048) are untouched. The "Fast Pass" / "Deep Pass" informal engineering names are retained.
- **Complete + consistent** — zero occurrences of "Initial Analysis" remain; the rename sits alongside "Outcome Analysis" (DL-138) with no surface left on the old vocabulary.
- **No forecast implication** — "Preliminary Outcome Analysis" names a *run*, not a score; it introduces no composite (D183b).
